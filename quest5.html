4. Debug and fix

Quest Section 2. 2 points.

Learn This block SHOULD report the sum of the odd numbers in nums. It has two mistakes.

Two things to know:

  • Inside the keep ring, the empty slot is where each item goes, one at a time. Putting nums there hands keep the whole list every time, not one number.
  • mod 2 gives the remainder after dividing by 2. Odd numbers have remainder 1. Even numbers have remainder 0.

Run it as written on nums = [3, 4, 7, 10, 5], one item at a time.

The fixed block

Two changes: the empty slot instead of nums, so keep tests one number at a time, and 1 instead of 0, so it keeps the odd numbers. Run it on the same list.

6. Keep, then map, then combine

Quest Section 3, second part. 0.5 points.

Learn The quest block: report the sum of every number in the list, doubled. sum the double of every number in the list [5, a, b, 4, c, 1050, :)] reports 2118.

Think about it from the inside out. What has to happen first? You cannot double "a". So first keep only the numbers. Then map to double each one. Then combine to add them up.
